# 연구 워크플로 에이전트

연구 아이디어를 계획서로 발전시키고, 관련 문헌을 수집한 뒤 PDF 파싱·검수까지 연결하는 한국어 프로젝트 지침 모음입니다.

## 구성

| 역할 | 지침 | 주요 작업 |
|---|---|---|
| 공통 운영 | [AGENTS.md](AGENTS.md) | 연구 ID, 폴더 구조, 역할 경계, 품질 게이트 |
| 연구계획서 | [작성 지침](00_에이전트/01_연구계획서/AGENTS.md) | 아이디어 구체화, 연구 설계, 계획서 작성·수정·점검 |
| 문헌수집 | [수집 지침](00_에이전트/02_문헌수집/AGENTS.md) | 관련 문헌 탐색, 원문 PDF 확보·검증, 수집 기록 |
| 파싱 | [파싱 지침](00_에이전트/03_파싱/AGENTS.md) | kordoc 파싱, 전체 페이지 자동 점검, 주요 페이지 원본 대조 |

## 사용 방법

1. 이 저장소를 내려받아 연구 작업공간으로 사용하거나, `AGENTS.md`와 `00_에이전트/`를 같은 구조로 작업공간에 복사합니다.
2. 파일 읽기·쓰기가 가능한 AI 에이전트에 공통 지침과 요청에 해당하는 역할 지침을 읽도록 요청합니다.
3. 새 연구의 아이디어를 제공하거나, 기존 연구의 ID와 수행할 작업을 명시합니다. 처음 사용하는 빈 작업공간에서는 `10_연구/`와 연구목록을 초기화하도록 함께 요청합니다.

요청 예시:

- “공통 지침과 연구계획서 에이전트 지침을 읽고, 새 연구 작업공간을 초기화한 뒤 내 아이디어를 연구계획서로 발전시켜줘.”
- “R2026-001의 문헌수집 전 품질 게이트를 점검해줘.”
- “품질 게이트 승인이 완료된 R2026-001의 핵심 문헌 PDF 5~10편을 수집하고 파싱·검수까지 진행해줘.”

## 실행 조건과 흐름

이 저장소는 프로젝트 지침 모음이며 별도 실행 프로그램이 아닙니다. 문서 생성, 웹 검색, PDF 다운로드, 렌더링에 필요한 도구는 사용하는 실행 환경에서 제공해야 합니다. 파싱 단계는 지침에 따라 Node.js 20 이상과 kordoc 사용 가능 여부를 확인합니다.

정식 계획서 기반 문헌수집은 품질 게이트와 필요한 사용자 검토를 거쳐 요청 시 시작합니다. 수집한 PDF의 확보·검증을 마치면 같은 작업에서 파싱·검수로 순차 전환합니다. 검색만·수집만 요청하거나 파싱을 제외한 경우에는 그 범위를 따릅니다. 계획서 반영은 별도 요청이 필요합니다.

실제 연구는 실행 시 `10_연구/<연구ID>_<짧은주제>/`에 생성합니다. 연구 원고, 수집 PDF, 파싱 결과, 개인정보 및 로컬 도구는 이 공개 저장소의 배포 범위에 포함하지 않습니다. 선택 사항인 `90_운영/연구폴더_템플릿/`은 포함하지 않았으며, 공통 지침의 구조에 따라 필요한 폴더를 생성할 수 있습니다.
